# 05  CAD: Escolha seu Software e Comece a Modelar

> **Objetivo:** Entender as opções de software, escolher o que faz mais
> sentido pra você, aprender onde estudar, e nunca perder um arquivo.

---

## 1. Não existe o CAD "certo"

A primeira coisa que precisa ficar clara é que o software não importa
tanto quanto a habilidade de modelar. Os conceitos são os mesmos em
todos eles: sketch, extrusão, montagem, detalhamento.

O que muda é a interface, o custo, e onde você vai encontrar ajuda
quando travar.

> Escolhe o CAD onde você consegue aprender mais rápido e onde alguém
> da equipe já tem experiência. Consistência dentro da equipe vale mais
> que o software "perfeito".

---

## 2. Os softwares que usamos (e suas diferenças reais)

### 🟦 Fusion 360  Autodesk
**Melhor pra quem:** está começando do zero, quer fazer CAD + CAM +
simulação num só lugar, ou quer integrar com impressão 3D.

- **Custo:** gratuito para estudantes e hobbyistas (licença pessoal)
- **Roda em:** Windows e Mac
- **Formato nativo:** `.f3d` / `.f3z`
- **Ponto forte:** tudo integrado  modelagem, simulação, geração de
  toolpath para CNC, e nuvem para versionamento automático
- **Ponto fraco:** mudou bastante nos últimos anos, tutoriais antigos
  podem estar desatualizados. Requer conta Autodesk.

---

### 🟥 SolidWorks  Dassault Systèmes
**Melhor pra quem:** quer aprender o padrão da indústria, ou pretende
trabalhar em engenharia mecânica profissionalmente.

- **Custo:** pago (caro), mas existe licença educacional via escola/universidade
- **Roda em:** Windows apenas
- **Formato nativo:** `.sldprt` (peça) / `.sldasm` (montagem) / `.slddrw` (desenho)
- **Ponto forte:** é o padrão da indústria no Brasil. Quem sabe
  SolidWorks não tem dificuldade em nenhum outro CAD paramétrico
- **Ponto fraco:** caro para ter de forma individual. Verifique se sua
  escola tem licença antes de ir atrás de alternativas.

---

### 🟧 Inventor  Autodesk
**Melhor pra quem:** já usa outros produtos Autodesk (AutoCAD, por
exemplo) ou está em ambiente escolar com suite Autodesk disponível.

- **Custo:** gratuito para estudantes via Autodesk Education
- **Roda em:** Windows apenas
- **Formato nativo:** `.ipt` (peça) / `.iam` (montagem) / `.idw` (desenho)
- **Ponto forte:** integração com AutoCAD, muito usado em cursos técnicos
  e universidades brasileiras
- **Ponto fraco:** menos conteúdo de qualidade em português para iniciantes
  comparado ao Fusion e SolidWorks

---

### 🟩 OnShape  PTC
**Melhor pra quem:** quer começar hoje sem instalar nada, ou quer
colaboração em tempo real (tipo Google Docs mas para CAD).

- **Custo:** gratuito para estudantes e projetos públicos
- **Roda em:** qualquer navegador, inclusive celular
- **Formato nativo:** na nuvem (sem arquivo local)
- **Ponto forte:** zero instalação, funciona em qualquer computador fraco,
  versionamento nativo, colaboração em tempo real
- **Ponto fraco:** projetos gratuitos são públicos. Não tem CAM integrado
  como o Fusion.

---

## 5. Salvando arquivos do jeito certo

Essa seção é tão importante quanto aprender a modelar.

### Formato nativo vs. formato universal

Cada CAD tem seu formato nativo  e esses formatos **não abrem em
outros softwares** sem conversão. Isso é um problema quando alguém
da equipe usa Fusion e outro usa SolidWorks.

A solução é sempre salvar em **dois formatos**:

```
minha-peca.f3d          ← arquivo nativo (editável)
minha-peca.step         ← arquivo universal (visualizável em qualquer CAD)
```

### O formato STEP (.step ou .stp)

STEP é o formato universal de CAD. Qualquer software abre,
qualquer pessoa consegue visualizar, e a geometria é preservada
com precisão.

Use sempre que precisar:
- Compartilhar com alguém de outro software
- Enviar para fabricação (corte a laser, usinagem CNC)
- Salvar uma versão "congelada" que não depende do software original
- Subir para GrabCAD ou Thingiverse

### Como exportar STEP em cada software

**Fusion 360**  
`File → Export → Format: STEP (.step)`

**SolidWorks**  
`File → Save As → Tipo: STEP AP214 (*.step)`

**Inventor**  
`File → Export → CAD Format → STEP`

**OnShape**  
`Clique direito na peça → Export → STEP`

### Outros formatos úteis

| Formato | Uso |
| :--- | :--- |
| `.step` / `.stp` | Universal, preserva geometria sólida  use sempre |
| `.stl` | Impressão 3D  geometria triangulada, sem cotas |
| `.iges` / `.igs` | Universal mais antigo, evite se tiver STEP disponível |
| `.pdf` | Desenho técnico 2D para documentação e fabricação |
| `.dxf` | Corte a laser  perfil 2D sem espessura |

## 6. Organização de arquivos no projeto

```
projeto-robo-seguidor/
│
├── cad/
│   ├── chassi/
│   │   ├── chassi-v1.f3d          ← nativo
│   │   ├── chassi-v1.step         ← universal
│   │   └── chassi-v2.f3d          ← próxima versão
│   │
│   ├── suporte-motor/
│   │   ├── suporte-motor.f3d
│   │   └── suporte-motor.step
│   │
│   └── montagem-completa/
│       ├── robo-completo.f3d
│       └── robo-completo.step
│
└── desenhos/
    ├── chassi-v1.pdf              ← desenho técnico para fabricação
    └── suporte-motor.pdf
```

**Regras de nomenclatura:**
- Sem espaços no nome do arquivo  use `-` ou `_`
- Sempre inclui versão: `-v1`, `-v2`, `-v3`
- Nunca apaga versões antigas  elas são seu histórico de projeto
- Antes de mandar fabricar, exporta um `.step` e confere no
  visualizador antes de enviar

## 7. Visualizadores gratuitos (para quem não tem o software)

Quando alguém precisar ver o arquivo sem ter o CAD instalado:

| Visualizador | Formatos | Como acessar |
| :--- | :--- | :--- |
| **eDrawings** (SolidWorks) | .sldprt, .step, .stl | Gratuito, instala no PC |
| **Autodesk Viewer** | .step, .f3d, .stl, .dwg | viewer.autodesk.com (browser) |
| **3D Viewer Online** | .step, .stl, .obj | 3dvieweronline.com (browser) |
| **OnShape** (público) | .step, .stl | onshape.com (browser, sem instalar) |

> Sempre sobe o `.step` junto com o nativo no repositório.  
> Qualquer pessoa consegue visualizar sem instalar nada.

## 8. Por onde começar amanhã

1. **Escolhe um software** da tabela do item 2
2. **Instala** (ou abre no browser, se for OnShape)
3. **Assiste o primeiro vídeo** do canal recomendado
4. **Faz o exercício mais simples possível:** um cubo com um furo
5. **Exporta em `.step`**
6. **Abre o `.step` em um visualizador** diferente e confirma que funcionou

Esse ciclo completo  modelar, exportar, validar  é o hábito mais
importante para desenvolver desde o início.
